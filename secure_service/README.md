# Swapnil AI Labs secure read-only service
Production-oriented release candidate, NOT production-certified. Supports finance, support, operations and knowledge categories with explicit tenant/category/record authorization. The application host independently establishes the requested record; the model can propose the same structured operation but cannot mint authority.
Run from source: python -m unittest -v secure_service.test_service ; python -m secure_service.smoke_http ; python -m secure_service.benchmark.
WSGI entrypoint: secure_service.http:from_env() (factory). Configure SWAPNIL_AI_LABS_DB, SWAPNIL_AI_LABS_PRINCIPALS (JSON with id, tenant, token_hash, categories, limit, budget), SWAPNIL_AI_LABS_AUDIT_KEY (hex >=32 random bytes). Provision data and ACLs through trusted administrative code before serving. No public provisioning endpoint. Do not expose wsgiref or test credentials. See docs/PRODUCTION_SOP.md, docs/SECURITY_ACCEPTANCE.md and datasets/README.md. This is a source deployment reference, not hosted infrastructure.
