# Install Swapnil AI Labs
The 72 local utilities run as a Progressive Web App (PWA). Serve /apps/ over HTTPS (localhost for development). Android Chrome: menu → Install app/Add to Home screen. iOS Safari: Share → Add to Home Screen. Desktop Chromium: install menu if offered. First successful online load is necessary for offline use; browser storage can be evicted. Only ten public shell assets are cached; no user inputs are persisted by the application. The research site outside /apps/ is not offline-enabled. Update the service worker cache version whenever shell assets change; use revalidation for sw.js and HTML. No native app-store submission or device install verified. No generative model connected. Public hosting is pending.
