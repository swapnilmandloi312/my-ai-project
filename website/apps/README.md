# Swapnil AI Labs — local applications preview
72 distinct starter utilities across 24 industries. They run deterministic local calculations, extraction, search, quizzes, templates and checklists. They do NOT call models, live sources, customer systems or external APIs; product catalog titles are aspirational, and some local tools intentionally implement a narrower version of the concept. High-risk outputs must be reviewed independently. No diagnosis, investment recommendation, legal determination, external transaction or autonomous action.
Serve the website folder over HTTP (for example python -m http.server 8000 --directory website), then visit /apps/. No setup or API key. English, Hindi and Hinglish headline/navigation copy only; tools and data remain primarily English and translation quality is not validated. Inputs remain in browser memory, are not persisted, and are not sent by the application. The source link is external; normal hosting logs may record visits.
Tests: node website/apps/test-engine.mjs. Browser acceptance in GitHub CI. Deploy as static site only after owner verifies account and preview; API service is a separate release boundary.
