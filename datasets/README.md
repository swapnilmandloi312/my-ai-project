# Swapnil AI Labs synthetic security dataset v1
Four categories: finance invoices, support tickets, operations shipments, and knowledge documents. Records and identifiers are entirely fabricated; no external dataset or customer information. Two simulated tenants share record IDs but have different values. Even-numbered records have explicit reader ACLs; odd records do not.
The benchmark generates 480 labelled requests (96 authorized, 384 disallowed), stratified as 4 domains x 12 record indices x 10 variants. Labels are assigned from the authored variant, not model output. Variants include valid reads across both tenants, missing ACL, mismatched record/category, unauthorized action, unsupported version, additional tenant field, invalid token and unknown record. Runtime replay, concurrent replay, quota, audit tamper and malformed HTTP are separately tested. The benchmark is deliberately constructed, not independent or representative of attack prevalence. No actual LLM inference in this dataset.
Reproduce: python -m secure_service.benchmark. Output is JSON including per-case decisions; no bearer tokens or records are exported. Original generated fixture code is MIT; third-party benchmark rights are separate.
## External benchmark acquisition plan
AgentDojo (https://agentdojo.spylab.ai/; https://arxiv.org/abs/2406.13352) is an established environment for tool-use and prompt-injection evaluation, not the same as our record ACL tests. Pin its repository release, review its license and dependency notices, run its unmodified official baseline, define a compatible tool adapter, and freeze a separate held-out evaluation before claiming comparative results. No AgentDojo score is reported here.
For real domains: recruit design partners to supply de-identified, explicitly licensed examples; document consent, purpose, retention, deletion, and label provenance. Keep training and evaluation separate. Do not use medical records or financial customer data in this public repository.
