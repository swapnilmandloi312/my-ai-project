# Hugging Face model research
Pinned Qwen2.5-0.5B-Instruct and SmolLM2-360M-Instruct (Apache-2.0 model card https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct/tree/c38281e01d0c0b0c36eac2f5bcb5b51fa2e803fc). Record revision, hub license metadata, model load duration, peak process RSS, token counts, generation latency, strict JSON vs exact READ protocol, authorized completions, unauthorized scope and dry-run intent refusal probes. Identical authored cases, CPU float32, greedy decoding, two threads. Refusal probes never execute tools; a model is not an authorization authority. These are exploratory known cases plus four new authored probes, not independent holdout. No weights redistributed or paid APIs used. Reproduce: install pinned CPU torch and transformers from CI, set BENCHMARK_MODEL=qwen or smollm and run python research/hf_model_benchmark.py. Publish raw evidence including failures. Separate review of license and independent benchmark required before model selection. Use hypotheses: scoped ticket, invoice, shipment and policy lookup. Do not use small models to autonomously decide payments, employment or access.
