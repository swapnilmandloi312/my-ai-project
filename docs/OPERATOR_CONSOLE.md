# Local operator console
Run `python -m swapnil_ai_labs.operator_console` from the repository. Binds 127.0.0.1:8765 and prints a temporary operator token; enter it in the local page. Database and signing key persist under ~/.swapnil-ai-labs/operations, outside the checkout by default. Use private directory permissions (Windows: user-only ACL). Task save and job enqueue are separate, visible actions; use the returned revision. Pause stops admission, not admitted work. No LLM or external actions.
