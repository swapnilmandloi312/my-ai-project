# Hourly scoped Python worker
The existing public repository uses a standard GitHub-hosted runner, bounded at 20 synthetic jobs per hourly invocation and five minutes total. It is not a continuous daemon and schedules can be delayed. The schedule is inert until repository variable SWAPNIL_WORKER_ENABLED=true. Only main is eligible. Never configure an admin database password. Migration 004 creates NOLOGIN sal_hourly_worker, with no direct table access or legacy cross-workspace claim privilege. Its private functions resolve exactly one workspace from session_user. Job approval, global stop, category pause and attempt cap remain authoritative. No model or business-tool calls, no monetary spending capability.

## Rollback
Unset SWAPNIL_WORKER_ENABLED, disable login with ALTER ROLE sal_hourly_worker NOLOGIN, revoke secret/rotate password, use emergency stop in founder UI. Existing session leases expire; emergency stop rejects stale completion. Role binding can be disabled by trusted SQL administrator. No credential created by migration.
