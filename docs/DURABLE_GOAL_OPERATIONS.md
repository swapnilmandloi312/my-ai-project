# Durable goal operations — local release candidate
Run python -m swapnil_ai_labs.goal_queue_demo for all 14 synthetic goal categories. Queue persists task revision, job ID, unique nonce, status, attempts, lease and result in SQLite. Bounded ticks process at most 32 jobs. Expired leases can be recovered within retry budget; committed evaluations are recovered from the goal-run table without another evaluation. Pause stops new claims; it does not interrupt already admitted work. Lease tokens guard finalization, and the GoalAgents one-use nonce prevents duplicate committed goal evaluation. Stale task revisions fail. Snapshot is for a trusted local host, not a web dashboard. Tests cover concurrent claiming, restart, lease recovery, exhaustion, tenant scope, idempotency and pause.

This is a deterministic evidence-gap evaluator, not a model-backed workforce or a hosted scheduler. Queue execution is explicitly limited to local read/evaluate behavior; lease expiry between validation and evaluation can still permit an already-admitted stale worker to perform a local evaluation, but cannot duplicate the committed nonce or finalize a replaced lease. This design must not be reused for external side effects without fencing and connector idempotency. No automatic retry of semantic failures. A trusted host controls tenant identity and signing keys; no external API, actual model execution, cloud cost budget, independently verified evidence or always-on server yet. Use independently authenticated host and explicit intent authority before integrating real model tools. Hourly ChatGPT operations scheduling is a separate service, not this local queue. Do not claim deployment or production safety.
