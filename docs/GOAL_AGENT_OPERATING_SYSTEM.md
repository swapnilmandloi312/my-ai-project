# Goal-driven agent operating system
Working v0.19 candidate. Ten internal roles (CEO/orchestration, research, engineering, model evaluation, security, product, growth, partnerships, finance, quality) plus four Work Relay department goal profiles. Every category has fixed objectives, required evidence references and a proposed next action. The local evaluator is deterministic: it does not use an LLM, autonomously schedule jobs, contact people, execute external tools, or verify document contents. Presence of all references means ready for independent review, never verified completion.

Run `python -m swapnil_ai_labs.goal_agent_demo`. Test `python -m unittest -v swapnil_ai_labs.test_goal_agents`. Host sets task and evidence at a specific revision, then issues a short-lived HMAC purpose grant binding tenant, task, category, revision and nonce. Run validates grant, denies expired/stale/wrong-scope/replayed requests and records outcome atomically. No user or model gets the signing key. Host caller is trusted, not an authenticated network service. No external side effects. Existing Work Relay and model runtime remain separate; these are reusable goal profiles, not live connectors.

Next: authenticated host identity, per-agent delegated credentials, explicit permissions for each tool, durable leased jobs and retry/kill policies, budget reservations, evaluation of independent evidence, external audit anchoring, real model planning under host-selected authority, approval for any side effect, and per-category acceptance evaluation. CEO may propose task assignments, never grant itself or others privileges. Keep human-approved independent release gates and design partner consent. Existing research automation and outreach campaigns are distinct from these local goal profiles. No claim of autonomous workforce or production readiness.
