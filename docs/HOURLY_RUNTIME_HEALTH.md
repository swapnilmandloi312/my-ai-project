# Hourly infrastructure observation
A private SQL collector measures actual queue state, lease expiry, membership count and authorization grants. It inserts one report per UTC hour with source database_cron, scope actual_operations, and explicit production_agent_execution=false. This is infrastructure monitoring, not a model call or a synthetic job. It never changes controls or claims/approves jobs; the execution emergency stop remains authoritative. It has no public RPC and is denied to browser and job worker roles. Administrator enables pg_cron on the existing project and schedules exactly one job: SELECT cron.schedule('swapnil-ai-labs-hourly-health','5 * * * *','SELECT sal_ops.collect_runtime_health(''swapnil-ai-labs'')'); disable with cron.unschedule('swapnil-ai-labs-hourly-health'). Verify cron.job and cron.job_run_details plus private run_reports. Manual collector test does not prove scheduled invocation. The existing database compute is used; no new service or model API is provisioned. Check database size and retention periodically. The collector does not estimate monetary costs. Python hosting and real department agents remain separate release gates.
