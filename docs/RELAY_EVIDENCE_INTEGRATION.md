# Work Relay evidence bridge
Internal Python integration for synthetic reviewer-only evidence retrieval. Both services independently authenticate the same principal ID and tenant. Trusted server selects the stored evidence reference from the current review revision, maps department to a fixed category, and calls the existing read-only runtime, which checks its own record ACL before model inference. It rechecks review state afterwards and returns metadata only. No approval, state change, document authenticity or external action. The two stores do not share a transaction; concurrent review changes may cause an authorized internal read to be wasted; stale results are discarded. Do not expose this internal adapter to the public web.

The alternate decision provider maps exact READ to the host's existing approved target, never to a model-selected target. Test against the original strict JSON method on the same eight known synthetic cases. This is exploratory reuse of known cases, not held-out model validation. A host must independently authorize user intent as well as record access; this classifier is not a reliable consent detector. Unauthorized cases are denied before either model is called. Future independent benchmark should include authorized records with disallowed or ambiguous user intent. No production claim.

Run: python -m unittest -v swapnil_ai_labs.test_relay_evidence swapnil_ai_labs.test_decision_provider. Model experiment uses pinned Qwen revision and dependencies in relay-evidence.yml. External dataset candidate: AgentDojo (https://github.com/ethz-spylab/agentdojo), with scope and license to be verified at a pinned revision; no claim of running AgentDojo.
