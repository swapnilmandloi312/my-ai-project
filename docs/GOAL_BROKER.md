# Authenticated goal broker v0.23 candidate
A local, synchronous WSGI boundary around the durable goal queue. Host-provisioned hashed bearer principals have fixed tenant and viewer/operator roles. No tenant supplied by caller. GET /v1/goals/status returns last 100 jobs and complete counts. POST /v1/goals/commands allows exact set_task, enqueue, pause, resume, and tick actions, capped at 14 jobs per tick. Persistent per-principal fixed-window 60/min quota; no arbitrary commands or outbound tools. Browser origins denied, not a cross-origin API. Evidence references are not verified claims. Audit records contain actor, tenant, action, outcome and timestamp; they are ordinary local rows, not tamper-proof or atomic with the command. A committed command can survive audit-write or response failure; inspect state before retrying. Pause stops new queue admission, not in-flight work. No live model execution, scheduler service, or automatic approvals. Authenticated operator can write local synthetic task data; no external effects.

Run `python -m swapnil_ai_labs.goal_broker_demo` and `python -m unittest -v swapnil_ai_labs.test_goal_broker swapnil_ai_labs.test_goal_queue swapnil_ai_labs.test_goal_agents`. Demo provisions fresh ephemeral credentials, runs actual loopback HTTP requests for all 14 categories, verifies pause/resume and restart. The hosted Founder Control Center remains separate and read-only. Next deployment gate: provision an owner-authorized private persistent backend, OIDC/session and same-origin CSRF controls, external audit, quota/storage/retention controls and independent security review. Existing legacy runtime routes still require network isolation; no claim of complete bypass prevention. Never expose development WSGI or use fixture credentials publicly. No hosted agent service deployed.
