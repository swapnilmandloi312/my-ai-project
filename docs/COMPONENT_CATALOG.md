# Swapnil AI Labs component catalog v0.7
Core platform: versioned proposals, fixed-stage compiler, read-only execution, tenant-bound grants, SQLite reference storage, evaluation, diagnostics, traces, model routing estimates, context ranking and scoped memory. Existing CI covers synthetic application behavior.
Additional independent prototypes: exact scoped cache with lexical similarity suggestions (not semantic embeddings), bounded knowledge graph, extractive sentence selection (not token-level adaptive compression), local versioned mailbox (not interoperable network protocol), and offline candidate metric gate (not autonomous self-improvement). These are reference utilities; they are not automatically wired into the unified runtime. No novel algorithm claim.
Future: real-model integrations and measured costs; held-out external evaluation; production identity and authorization; independent security review; calibrated semantic cache and compression; interoperable agent communication; multilingual dataset and model adaptation; efficient inference research; broader platform control plane. Train no model without lawful datasets, reproducible baseline and budget.
