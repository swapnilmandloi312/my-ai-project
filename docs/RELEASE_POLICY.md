# Swapnil AI Labs — release policy
Source milestones use semantic version labels (pre-1.0 experimental). Proposal contract versions are independent of package versions; reject incompatible inputs rather than silently reinterpret them. Document all breaking changes in CHANGELOG.md, add compatibility tests, provide migration and rollback instructions.
Build wheel artifacts in CI, smoke-test installation in a clean environment, preserve SHA-256 checksums and test logs against commit SHA. These artifacts are internal research previews; do not publish to PyPI, npm, registries or production without release approval and dependency-rights review. Before shipping external dependencies, add SBOM, provenance attestations, vulnerability review and third-party notices. Do not interpret a green workflow as production approval.
