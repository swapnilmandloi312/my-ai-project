# Swapnil AI Labs — task-first public preview
v0.12 adds a guided experience for learning, business cash review, document source extraction, agent evaluation, and research evidence organization. The legacy 72 utilities remain at /apps/tools.html. Goal matching uses transparent keyword rules with explicit ambiguity handling; it is not a language model. Five workflows use deterministic calculations or source-preserving organization and structured inputs, with limitations visible on every result. No voice, file upload, external retrieval, user accounts or autonomous actions are enabled. No data is persisted by the app. Financial, legal, health and scientific interpretations require qualified review.
Release gate: engine tests, real Chromium mobile workflow tests, existing 72 utility browser checks, offline service worker checks. Future: source-backed model adapter and evaluation, independent review, accessible multilingual journeys, consent-based storage, redacted uploads. Do not market this version as a general AI assistant.
