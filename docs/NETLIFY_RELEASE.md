# Netlify release and rollback
The standalone research website can be built using `python scripts/build_public_site.py`. The resulting dist-public directory is the deployable artifact. netlify.toml configures the same build when this repository is connected to a Netlify site. Do not replace an existing site until the authenticated owner identifies the current site ID, source repository, production deploy and rollback method. If preserving the previous homepage, merge the new pages into its actual source tree or use a separate preview site; this release intentionally does not assume access to the existing source. Check HTTPS, root, /apps/, /apps/tools.html, service-worker update and rollback on the actual hosted domain. Deployment permissions and verification remain separate. No API keys or credentials should be put in Git or chat.
