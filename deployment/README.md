# Single-node staging deployment
This recipe builds a non-root Gunicorn image with a hash-pinned server wheel. The CI harness provisions random test-only credentials, binds the service to runner loopback, drops capabilities, uses a read-only root filesystem, runs concurrent reads and negative checks, creates a consistent SQLite backup, verifies its audit chain and checks replay after restart.
Run from source: python deployment/staging_acceptance.py (requires Docker). This is an isolated staging acceptance test, not a public service or scale benchmark. No real customer data. See docs/PRODUCTION_SOP.md before deploying anywhere.
Remaining release gates: approved base-image digest and full dependency/OS SBOM, vulnerability scan, signed artifact, production TLS reverse proxy and edge quotas, external workload identity and user consent/ACLs, encrypted secret storage, external immutable audit anchor, distributed storage and failover, independent threat review and load/soak tests. Do not expose this container directly to the public Internet. Never use synthetic seed in production.
