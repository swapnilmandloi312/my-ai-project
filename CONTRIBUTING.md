# Contribute to Swapnil AI Labs
Open research, reproducible engineering and honest claims.
1. Open an issue describing the problem, prior art, proposed baseline, intended scope and acceptance tests.
2. Create a feature branch. Keep changes small and document architecture decisions. Run the relevant Python and integration suites; include reproducible logs.
3. For research, freeze evaluation cases, report failures, publish only permitted data, and identify measured versus synthetic quantities. See docs/RESEARCH_STANDARD.md.
4. Submit a PR with tests, limitations, security considerations and backwards compatibility. Do not merge failing checks.
5. Only submit contributions you have the right to license under MIT. Third-party materials retain their own licenses. Never commit secrets, identifiable customer data, unlicensed datasets or model weights.
Security reports: use a private channel through the maintainer if available; do not disclose exploit details or real credentials in public issues.
