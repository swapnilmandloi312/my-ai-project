# Swapnil AI Labs — commercial discovery
Initial offer: a two-week scoped read-only agent reliability pilot using synthetic or customer-approved non-sensitive data. Proposed price $1,500–3,000, negotiable after scoping; no customer commitment or proven market rate.
Acceptance: mutually approved workload and authorization boundary, measured legitimate completion and unauthorized execution separately, comparison to existing customer baseline, reproducible logs, rollback, no privileged production integration without separate security approval.
Discovery questions: What tools does the agent call? What must never happen? How is tenant identity established? What existing policies apply? How are costs and human approvals managed? What is the failure rate and cost today?
Marketing: use actual model failure and corrected replay; label all synthetic/recorded evidence. Invite engineers to reproduce results, not to trust a security guarantee.
Pilot pipeline: qualification → architecture call → synthetic demo → scope and acceptance criteria → paid pilot → measured outcome → customer-approved case study. Do not promise results or publish customer identities without consent.
