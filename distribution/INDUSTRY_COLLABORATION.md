# Company collaboration playbook
Offer: one narrow reproducible integration or evaluation, non-sensitive, no production security promise. Link the public source, exact experiment, and expected acceptance criteria.
For tool providers: show complementary app-level action scope alongside their authentication. For orchestration platforms: demonstrate failure diagnosis and holdout evaluation using a read-only tool. For model vendors: propose reproducible model compatibility and tool-call utility/safety checks. For evaluation platforms: propose shared labelled cases and evidence trace export.
Research public company docs and confirm contact from an official public business source before sending. Check sent mail to prevent duplicates; prefer existing relevant threads if appropriate. Stop after opt-out; follow up once with a meaningful new artifact, not a generic bump. Maintain a private contact log rather than publishing email addresses in this repository.
Success metrics: actual sent messages, replies, accepted technical calls, contributed integrations, independent reproductions, scoped pilots and measured customer outcomes. Do not report pipeline opportunities as clients.
