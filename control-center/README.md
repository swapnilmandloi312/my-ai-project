# Founder Control Center v0.22
Static read-only engineering dashboard with live public GitHub REST feeds: issue #3, latest 30 PRs, latest 30 CI runs. Five-minute visible-tab refresh, partial failure reporting, checklist search/filter, CSV with spreadsheet formula protection, historical benchmark and 14 profile baseline. Uses no secrets, no private data in source. Local private report JSON schema sal.operations.v1: generated_at ISO time; runs array of title,status,summary,run_id,completed_at (ISO or null). Import stays in memory only and is cleared on reload. No live ChatGPT automation API, privileged actions, hosted job service, or customer data. GitHub anonymous API rate limits apply; partial data may be stale. Run node control-center/test.mjs. Serve control-center over HTTP for module support. Deploy this directory separately with Vercel authentication; no changes to Netlify or existing Vercel app. Do not claim authentication login or hosted runtime verified until tested. No external writes.
