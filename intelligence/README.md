# Swapnil AI Labs — Intelligence components v0.4
Implemented experimental BM25 context selection (whitespace-word budget), persistent scoped memory with expiry/provenance labels, constrained deterministic routing using hypothetical estimates, and a persistent synthetic finance authorization store. These are standard algorithm implementations and reference components, not novel research discoveries.
Run python -m unittest -v intelligence.test_components intelligence.test_authorized_store and python -m intelligence.benchmark.
The authorization store is a local trusted-host demonstration: one-use grants, request binding, expiry, transactionally consumed budgets and audit rows. It has no production identity provider, external audit integrity anchoring, network API, rate limiting, key rotation or real customer data. Memory provenance is supplied by a trusted host, not verified by the database. Model routing does not measure real model accuracy or price. Context ranking is lexical, not LLM token compression.
Prior art: https://aclanthology.org/2024.acl-long.91/ ; https://github.com/xiaowu0162/LongMemEval ; https://arxiv.org/abs/2406.18665. No direct empirical comparison to these projects yet.
